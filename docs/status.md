## 既知の制限

- **チャット表示**: herdr の連携（`herdr integration install claude` / `codex`）が入っているホストでしか使えません。
- **SSH**: パスワード認証や対話式の認証には対応していません。鍵で入れるようにしておく必要があります。
- **herdr-core**
  - 画面は色なしでしか読めません。
  - 入力待ちのエージェントに、下書きを入れることができません（core にその API がない）。
- **使用量**
  - 利用上限（5 時間枠や週の枠の残り）は出しません。
  - 価格表にないモデルのコストは出ません（`*` が付きます）。
- **Windows のホスト**: 対象外です。
- **リモートの使用量**: そのマシンに koolie が入っている必要があります。
